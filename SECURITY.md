# Política de seguridad

## Reportar una vulnerabilidad

**No abras un issue público.** Usá el reporte privado de GitHub:
**Security → Report a vulnerability** ([abrir reporte](https://github.com/AlbertiJ/vpn-prioridad/security/advisories/new)).

Incluí: qué pasa, cómo reproducirlo, el impacto y, si podés, una sugerencia de arreglo.
Respondo en cuanto puedo y coordinamos juntos cuándo publicar el arreglo.

## Datos sensibles

Si encontrás en este repositorio un dato que no debería ser público (credenciales, correos, rutas de equipos),
avisame por el mismo canal privado.
